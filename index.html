Release notes

What's new in v1.7.10

Five releases since v1.7.5: a safer data location, a new update flow, a fixed slideshow timer, a countdown that shows seconds, and clearer update errors.

When a check fails, you'll know why

v1.7.10 explains timeouts, DNS/TLS failures, GitHub rate limits (with reset time), 404s and 5xx server errors, and adds an Open Release Page button.

A safer, sturdier base

v1.7.6 moved your data to %LOCALAPPDATA%\FrogPaper, so rebuilds and uninstalls no longer touch your wallpapers, tags or favourites. It also pins Pillow 13.0.0 and NLTK 3.10.4, and repairs the OpenCV style filters.

Updates you control

v1.7.7 removed the in-app auto-installer. Install Update now opens the release page in your browser, and the installer force-closes a running FrogPaper so the file is replaced cleanly. v1.7.8 adds a Check for Updates button in Settings → Help.

The slideshow timer actually waits

v1.7.8 stops the slideshow from changing your wallpaper one second after launch, and applies a new interval immediately instead of leaving the old timer running. Fresh installs now default to slideshow off at 60 minutes.

A countdown you can see

v1.7.9 shows seconds in the slideshow countdown — 11h 59m 42s instead of a static-looking 11h 59m. The progress bar still fills continuously.

A helping hand

Good questions. Clear answers.

Will I lose my wallpapers, favorites, or settings?

No. Upgrading never touches your data: wallpapers, the gallery with its tags, pinned favorites, presets, your config and cloud connections all carry over untouched.

How do I upgrade?

Download the latest installer and run it over your existing install. That's it. From source, extract the update zip over your project folder and allow replacing all files.

Do I need to set up my AI provider again?

No. Your provider choice, API keys and settings load exactly as they were.

What should I check after updating?

Open Cloud & Backup and run “Check backup…” — it downloads a sample and confirms every image is readable. Then run a sync twice: the second pass should report 0 added and upload nothing.

Will restoring duplicate my images?

No. Restore checks the content of every file against the images already in your library and skips anything it already has, so the same picture will not appear twice.

What if a file still can't be read?

The backup check names the files it cannot read instead of failing generically. Run it again after a sync; anything still unreadable is reported by name so you can deal with that one file.

Does the latest update change how the app looks?

No visual overhaul. v1.7.6–v1.7.10 focus on security, where your data lives, the update flow, the slideshow timer and clearer update errors; the themes and layout are unchanged.

Did older versions add frogs to my images without asking?

Yes — earlier builds contained a hard-coded “frog bias” that could occasionally add a frog cameo to blank-subject images. It was fully removed in v1.6.1, and frogs are now controlled by the Frog Sneak setting (Settings → Generation). Set it to off if you would rather they never appear; images you already have are untouched.

Is FrogPaper free?

Yes. Both apps are free and open source. The Windows installer and Android APK cost nothing; optional AI providers may have their own free tiers or paid keys.

Do I need an account?

No. There is no FrogPaper account to create and no FrogPaper server in the middle. Windows keeps your library on your PC; Android keeps every wallpaper on your phone.

Where are my wallpapers stored?

On Windows, wallpapers live in your library on your PC, with optional backup to Google Drive, OneDrive or Dropbox. On Android, wallpapers are saved on the device and nothing is uploaded anywhere.

Does the Android app work offline?

Yes. It works offline from the copies on your phone, and automatic wallpapers use the engine you picked. If a run fails, the app tells you when it will retry.
