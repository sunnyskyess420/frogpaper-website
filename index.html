Model Setup Guide Intermediate

Configure AI providers and set up models

AI Provider Setup

FrogPaper supports multiple AI providers. Let's configure them for the best experience.

Option 1: Pollinations.ai (Free)

The easiest option! Pollinations.ai is completely free and requires no setup. Just select it from the provider dropdown and you're ready to generate.

Option 2: Cloudflare Workers AI

You'll need an API token from dash.cloudflare.com and your Account ID. Go to Workers AI, click Use REST API, and create a token.

Setting Up Cloudflare

In Settings, select Cloudflare Workers AI from the provider dropdown. Enter your token in the Cloudflare Token field and your Account ID.

Option 3: HuggingFace

HuggingFace offers access to many models. You'll need an API token from huggingface.co under Settings, then Access Tokens.

Choosing the Right Model

FLUX models are great for realistic images, SDXL models work well for artistic styles. Experiment to find your favorites!

Testing Your Setup

After configuring your provider and token, try generating a simple wallpaper. If it works, you're all set! If you see errors, try the free Pollinations.ai option.
