Features

Six AI providers, one app.

Pick the backend that fits your budget and speed — free options, pay-per-image, or premium quality. Switch anytime with dynamic setup guides.

6 AI Providers

Pollinations (free), Cloudflare Workers AI (free), HuggingFace, Prodia, Replicate, and Fal.ai. Switch in Settings and the UI adapts instantly.

Dynamic Provider Setup

Switch providers and the panel shows only that provider's API key field plus a step-by-step setup guide with clickable links. No guesswork.

Resolution Freedom

Choose 16:9, portrait, or square. If a provider only outputs 1024×1024, FrogPaper resizes to your target with lossless LANCZOS scaling.

Blazing Fast Polling

Replicate generations dropped from ~65s to ~8s thanks to optimized 1-second polling instead of slow long-poll connections.

Star-Pinned Favorites

Every dropdown option carries its own star button. Pin your go-to subjects, moods, and lighting — they rise to the top, always one click away.

Safer by Design

API keys are never packed into the EXE. Fresh installs start from a clean template, and every build passes an automated secret scan before packaging.

Release Notes

What's new in v1.5.0

The quality release: a faster gallery, full keyboard control, and friendlier errors — plus the biggest internal cleanup in FrogPaper's history.

Speed

  • Gallery views open instantly — thumbnails decode in a background worker, cache hits render immediately.
  • Sorting by image size pays each header read once, then is instant.
  • Gallery re-grids on an 80ms debounce instead of on every window event.

Reliability

  • Friendly error dialogs for gallery delete/move failures and unreadable data files.
  • Starter dropdown defaults survive launching with "remember settings" OFF.
  • Prompt engine preserves your capitalization and applies thesaurus edits without a restart.
  • Fixed a startup crash affecting some installs.

Accessibility

  • Full keyboard navigation — every custom button and dropdown row is reachable via Tab, activated with Enter/Space, with focus rings that adapt to the theme.
  • Tab no longer gets stuck inside the negative-prompt Preview or any text editor.
  • Dropdown popups auto-fit their widest item instead of clipping at large font sizes.

Under the Hood

  • Modular rewrite — app.py went from 8,891 lines to ~2,600 across focused modules, behavior unchanged.
  • 301 automated tests, up from 84 — including a real-app startup smoke test.
  • CI runs lint plus the full suite on a real Windows runner on every push.

Upgrading to 1.5.0

Short version: run the new installer over the old one — your stuff stays.

Will I lose my wallpapers, favorites, or settings? +

No. Upgrading never touches your data: wallpapers, the gallery with its tags, pinned favorites, presets, your config, and cloud connections all carry over untouched.

How do I upgrade? +

Download the 1.5.0 installer and run it over your existing install. That's it. From source, extract the update zip over your project folder and allow replacing all files.

Do I need to set up my AI provider again? +

No. Your provider choice, API keys, and settings load exactly as they were.

What should I try first after updating? +

Press Tab in the prompt builder — every control is now keyboard-reachable, with visible focus rings. Then open the gallery: Favorites and Styled views open noticeably faster.

Does 1.5.0 look different? +

No visual redesign — this release is speed, keyboard control, and reliability. Same FrogPaper, fewer rough edges.
